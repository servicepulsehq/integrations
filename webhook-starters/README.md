# Outbound webhook starters

Small apps that **verify** ServicePulse **outbound webhook** signatures before handling JSON payloads.

| Stack    | Folder            |
|----------|-------------------|
| Express  | [nodejs-express](./nodejs-express/) |
| FastAPI  | [python-fastapi](./python-fastapi/) |

Configure the URL and secret under **Settings → Notifications** in ServicePulse (Team plan).
